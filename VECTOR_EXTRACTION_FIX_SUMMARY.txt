ISSUE FIXED:
-----------
When processing large PDFs with multiple pages, vector extraction was:
  ❌ Extracting useless measurements: 6", 4", 30", 8", 2", 12", 9", 5/8"
  ❌ Processing image-only pages (scanned pages with no vector content)
  ❌ Not filtering bare numbers from actual plumbing symbols
  ❌ Mixing up measurements with symbol labels

SOLUTION: THREE KEY IMPROVEMENTS
================================

1️⃣  PAGE-LEVEL VECTOR DETECTION
    Added intelligent detection to distinguish:
    ✅ Vector-based pages (CAD drawings) - Process these
    ❌ Image-only pages (scanned images) - Skip these
    
    Threshold: Pages with < 8 text elements are considered image-only

2️⃣  STRICT SYMBOL VALIDATION
    Changed from loose pattern to STRICT validation:
    
    OLD: Accepted bare numbers like "6"", "4"", "30""
    NEW: REJECTS bare numbers, REQUIRES context
    
    ❌ REJECTS: "6"", "4"", "30"", "8"", "2"", "5/8"" (bare measurements)
    ✅ ACCEPTS: "4" CW", "1/2" NG", "1 1/2" SAN" (with abbreviations)
    
3️⃣  ENHANCED LOGGING
    Detailed diagnostic output showing:
    - Which pages are vector-based
    - Which pages are image-only (skipped)
    - How many bare measurements were rejected
    - Final clean symbol list

VALID SYMBOLS NOW ACCEPTED
===========================

Pattern 1: Fixture Codes
  WC-1, WC-2, AC-1, LAV, UR-1, FD-1, etc.

Pattern 2: Pipe Sizes with Abbreviations
  4" CW     (4-inch Cast Water)
  3/4" HW   (3/4-inch Hot Water)
  1/2" NG   (1/2-inch Natural Gas)
  1 1/2" SAN (1-1/2-inch Sanitary)
  1" GW     (1-inch Grease/Waste)
  And many more with CW, HW, HWR, NG, SAN, GW, V, FP, CD, CA, ST, OST

Pattern 3: Routing Symbols
  UP, DOWN, RISER, DROP, RISE, BRANCH, CONNECTION, POC

Pattern 4: Known Abbreviations
  CLEANOUT, METER, THERMOMETER, VALVE, etc.

===============================================================================

NOISE NOW BLOCKED
=================

Single Measurements (REJECTED):
  "6"", "4"", "30"", "8"", "2"", "12"", "9"", "5/8""
  
Why: These are measurement dimensions, not symbols
     Symbols must have TYPE context (CW, HW, NG, etc.)

Generic Words (REJECTED):
  AREA, ROOM, SPACE, KITCHEN, PLAN, NOTES, etc.
  
Equipment Names (REJECTED):
  OVEN, RANGE, DISHWASHER, TABLE, etc.
